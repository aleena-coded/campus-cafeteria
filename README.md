# Campus Bites - Campus Cafeteria Website

A small informational website for the fictional university cafeteria "Campus Bites".
Built with plain HTML and CSS as part of DevOps Fundamentals, Assignment 01.

## Pages
- Home (`src/index.html`)
- Menu (`src/menu.html`)
- Deals (`src/deals.html`)
- How to Order (`src/order.html`)
- Feedback & Contact (`src/feedback.html`)

## Branches
- `main`: production-ready code
- `develop`: active development
- `feature/<page-name>`: one branch per page
- `release/v1.0`: QA and testing

## How to run
Open any file in `src/` in your browser.
